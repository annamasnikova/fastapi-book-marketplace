# 📚 Book Marketplace API (FastAPI)

## 📌 Goal
Develop a backend service for a book marketplace.

## ⚙️ Features
- Seller registration  
- CRUD operations for books  
- One-to-many relationship (Seller → Books)

## 🔌 API Endpoints
- POST /seller  
- GET /seller  
- GET /seller/{id}  
- PUT /seller/{id}  
- DELETE /seller/{id}  

## 🛠️ Tech Stack
- FastAPI  
- PostgreSQL  
- SQLAlchemy
